# 木版水印分版与印制推演系统

浏览器内运行的木版水印数字化工作台：原画自动分版、版块编辑、水色/宣纸建库、
Beer–Lambert 物理叠印推演、拱花侧光、套准偏差模拟、色差定位与刻版图工艺单。
纯 TypeScript + WebGL2 自研着色器，数据全部落在 IndexedDB，无后端。

## 启动

```bash
pnpm install
pnpm dev        # 本地开发，自动开浏览器
pnpm build      # tsc 类型检查 + 生产构建
node test/run.ts  # 领域算法测试（Node 24 原生执行 TS）
```

首次打开会自动生成三幅示例画稿（花鸟、山水、拱花笺纸）与 8 种水色、4 种宣纸，
也可用左下角按钮重新载入。

## 核心技术设计

### 1. 叠色为什么准——Beer–Lambert 减法混色

透明水色不是不透明涂料，不能用 alpha 覆盖。每块色版在着色器里表达为每通道
吸收系数 A，落色时对累积线性光做透射率相乘：

```
T_c = exp(-A_c × 覆盖率 × 刷色遍数)
结果线性光 = 当前线性光 × T
```

- 全程在线性光空间（sRGB 先解码）运算，最后才编码回 sRGB 显示
- 乘法天然满足交换/结合律，多版叠印物理自洽，重复刷色只深不浅
- 颜色变化只改 uniform，不碰纹理，30 版改色是 30 个全屏 pass 的毫秒级开销

### 2. 为什么两次推演完全一致

- 全项目禁用 `Math.random`；纸纹、飞白、聚类初值全部走种子化哈希（mulberry32/fbm）
- 模拟分辨率按固定规则取整，不随窗口变化
- 每次推演读回全部像素做 FNV-1a 校验和，页面上展示并写入历史
- 推演页"一致性自检"按钮连跑两次逐像素比对，测试套件覆盖同种子序列与校验和稳定性

### 3. 性能结构

- 版块掩码（栅格化 + 纸纹颗粒 + 纤维向高斯晕化）按 `版块几何 + 纸张 + 晕化参数`
  缓存为 R8 纹理；改颜色/浓度/顺序完全不重烘焙
- 颜色累积用 RGBA16F 乒乓 FBO；A 通道记录"最后落色版块序号"，tonemap 前 blit
  快照，供画面点击定位责任版块
- 高度场单独一对 FBO 累积拱花凹凸，差分求法线做侧光，仰角 90 度（正面光）阴影消失

## 关键参数物理含义

- `expansionPctX/Y`：纸受潮纤维涨开百分比，着色器里把版纹按中心反向缩放，
  正值表现为图文相对纸边内缩
- `offsetXMm/YMm`：单块版相对规矩线的毫米级错位，按作品物理幅面换算 UV
- `bleedScale`：晕化全局倍率；各向异性半径由纸张吸水性与纤维方向决定
- `lightElevationDeg`：光源仰角，越低拱花阴影越重，90 度正面光几乎不可见
- 色差统计用 CIEDE2000（CPU 精确，抽稀采样），热图用 Lab 欧氏距离做实时可视化
